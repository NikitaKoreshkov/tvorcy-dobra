# Безопасность системы

## Реализованные меры безопасности

### 1. Хэширование паролей
- **Argon2id** - современный алгоритм хэширования паролей
- Параметры: memoryCost: 64MB, timeCost: 3, parallelism: 4
- Защита от rainbow tables и brute force атак

### 2. JWT токены
- Обязательные токены для авторизации
- Срок действия: 7 дней (настраивается)
- Валидация токенов на каждом защищенном endpoint

### 3. Rate Limiting
- Глобальный лимит: 10 запросов в минуту
- Отправка кода: 3 запроса в минуту
- Вход/регистрация: 5 запросов в минуту
- WebAuthn: 10 запросов в минуту

### 4. Защита от брутфорса
- Максимум 5 неудачных попыток входа
- Блокировка аккаунта на 15 минут после превышения лимита
- Увеличивающаяся задержка при неудачных попытках
- Логирование всех попыток входа

### 5. Валидация email
- Проверка формата email
- Блокировка временных email сервисов (tempmail, 10minutemail и др.)
- DNS проверка домена email
- Защита от фейк email адресов

### 6. Защита от SQL инъекций
- TypeORM с параметризованными запросами
- Валидация всех входных данных
- Whitelist для DTO

### 7. Защита от XSS
- Валидация всех входных данных
- Helmet для HTTP заголовков безопасности
- Content Security Policy

### 8. Коды подтверждения
- Срок действия: 15 минут
- Максимум 5 попыток ввода кода
- Автоматическое удаление использованных кодов
- Защита от перебора кодов

### 9. Middleware безопасности
- Проверка SQL инъекций в query параметрах
- Проверка XSS в body запросов
- Валидация всех входных данных

### 10. Мониторинг подозрительной активности
- Отслеживание неудачных попыток входа
- Обнаружение множественных IP адресов
- Блокировка при обнаружении подозрительной активности

## Настройка базы данных

1. Создайте базу данных PostgreSQL:
```sql
CREATE DATABASE donate;
```

2. Настройте переменные окружения в `.env`:
```
DB_HOST=localhost
DB_PORT=5432
DB_USERNAME=postgres
DB_PASSWORD=your_password
DB_DATABASE=donate
JWT_SECRET=your-very-long-secret-key-min-32-chars
```

3. TypeORM автоматически создаст таблицы при первом запуске (только в development режиме)

## Важные замечания

- **НЕ используйте** `synchronize: true` в production
- **Измените** JWT_SECRET на уникальный длинный ключ
- **Настройте** правильные CORS настройки для production
- **Используйте** HTTPS в production
- **Настройте** rate limiting в зависимости от нагрузки
