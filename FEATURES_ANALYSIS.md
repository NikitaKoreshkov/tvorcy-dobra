## 🔐 БЕЗОПАСНОСТЬ

### 1. Аутентификация
- JWT токены (7 дней действия)
- Argon2id хэширование паролей (memoryCost: 64MB, timeCost: 3, parallelism: 4)
- Google OAuth интеграция
- Email верификация
- 6-значные коды подтверждения (15 минут действия)
- Биометрическая аутентификация (biometricIdHash)

### 2. Защита от атак
- Rate limiting:
  - Глобальный: 10 запросов/минуту
  - Отправка кода: 3 запроса/минуту
  - Вход/регистрация: 5 запросов/минуту
- Защита от брутфорса:
  - Максимум 5 неудачных попыток
  - Блокировка на 15 минут
  - Увеличивающаяся задержка
  - Логирование всех попыток
- Валидация email:
  - Проверка формата
  - Блокировка временных email сервисов
  - DNS проверка домена

### 3. Защита данных
- Защита от SQL инъекций (TypeORM с параметризованными запросами)
- Защита от XSS (валидация, Helmet, CSP)
- Helmet для HTTP заголовков безопасности
- Content Security Policy
- CORS настройки
- Whitelist для DTO

### 4. Безопасность платежей
- Токенизация карт
- Шифрование данных карт
- Fingerprint для обнаружения дубликатов
- Валидация данных карт
