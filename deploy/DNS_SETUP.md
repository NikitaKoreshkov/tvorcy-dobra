# Инструкция по настройке DNS и SSL сертификатов

## Текущий IP сервера: 91.229.11.210

## Настройка DNS записей

### Для всех доменов нужно создать A записи:

#### Английские домены:
- **charityfond.online**
- **charityfond.ru**
- **charityfond.store**

#### Русские домены (.рф):
- **творцыдобра.рф**
- **творецдобра.рф**
- **странадобра.рф**
- **творцы-добра.рф**
- **творец-добра.рф**
- **страна-добра.рф**

### Инструкция по настройке DNS:

1. Войдите в панель управления вашего регистратора доменов (Reg.ru, Timeweb, и т.д.)

2. Для каждого домена создайте следующие A записи:

   **Для корневого домена:**
   ```
   Тип: A
   Имя: @ (или оставьте пустым)
   Значение: 91.229.11.210
   TTL: 3600 (или автоматически)
   ```

   **Для поддомена www:**
   ```
   Тип: A
   Имя: www
   Значение: 91.229.11.210
   TTL: 3600 (или автоматически)
   ```

3. Повторите для всех доменов

4. Подождите 5-10 минут для распространения DNS записей

### Проверка DNS записей:

После настройки проверьте, что домены указывают на правильный IP:

```bash
dig +short charityfond.online
dig +short www.charityfond.online
# Должно вернуть: 91.229.11.210
```

Или используйте онлайн-сервисы:
- https://dnschecker.org
- https://www.whatsmydns.net

## Получение SSL сертификатов

После настройки DNS записей выполните на сервере:

```bash
ssh root@91.229.11.210
cd /var/www/charityfond
./deploy/setup-dns-ssl.sh
```

Или вручную:

### Для английских доменов:

```bash
certbot --nginx \
    -d charityfond.online \
    -d www.charityfond.online \
    -d charityfond.ru \
    -d www.charityfond.ru \
    -d charityfond.store \
    -d www.charityfond.store \
    --non-interactive \
    --agree-tos \
    --email cpvart@mail.ru \
    --redirect
```

### Для русских доменов:

```bash
certbot --nginx \
    -d творцыдобра.рф \
    -d www.творцыдобра.рф \
    -d творецдобра.рф \
    -d www.творецдобра.рф \
    -d странадобра.рф \
    -d www.странадобра.рф \
    -d творцы-добра.рф \
    -d www.творцы-добра.рф \
    -d творец-добра.рф \
    -d www.творец-добра.рф \
    -d страна-добра.рф \
    -d www.страна-добра.рф \
    --non-interactive \
    --agree-tos \
    --email cpvart@mail.ru \
    --redirect
```

**Примечание:** Для кириллических доменов (.рф) может потребоваться использовать DNS challenge вместо HTTP challenge, если Certbot не может проверить домен через HTTP.

### Использование DNS challenge (если HTTP не работает):

```bash
certbot certonly --manual --preferred-challenges dns \
    -d творцыдобра.рф \
    -d www.творцыдобра.рф \
    --email cpvart@mail.ru \
    --agree-tos
```

Certbot покажет TXT запись, которую нужно добавить в DNS, затем нажмите Enter.

## Автоматическое обновление сертификатов

Certbot автоматически настроит обновление сертификатов. Проверить можно командой:

```bash
certbot certificates
systemctl status certbot.timer
```

## Проверка работы HTTPS

После получения сертификатов проверьте:

```bash
curl -I https://charityfond.online
curl -I https://творцыдобра.рф
```

Все должно возвращать HTTP 200 или 307 (редирект).

## Обновление конфигурации Nginx

После получения сертификатов Certbot автоматически обновит конфигурацию Nginx. Проверьте:

```bash
nginx -t
systemctl reload nginx
```

## Устранение проблем

### Если DNS не обновляется:

1. Проверьте TTL записей (должен быть низким, например 300-600)
2. Очистите DNS кэш: `sudo systemd-resolve --flush-caches` (на клиенте)
3. Подождите до 24 часов для полного распространения

### Если Certbot не может получить сертификат:

1. Убедитесь, что домен указывает на правильный IP
2. Проверьте, что порты 80 и 443 открыты в firewall
3. Попробуйте использовать DNS challenge вместо HTTP challenge
4. Проверьте логи: `tail -f /var/log/letsencrypt/letsencrypt.log`

### Если сертификат не обновляется автоматически:

```bash
certbot renew --dry-run
```

Если тест прошел успешно, сертификаты будут обновляться автоматически.
